## Timesheet Management System (`ticktock`)

A full-stack, responsive web application designed for tracking employee weekly timesheets, daily tasks, and work logs. Built with Next.js (App Router), TypeScript, and Tailwind CSS.

---

## Frameworks & Libraries

* *Core Framework* : [Next.js (App Router)]
* *Language* : [TypeScript]
* *Styling* : [Tailwind CSS]
* *Icons* : [Lucide React]
* *Typography* : [Google Fonts (Inter)]

---

## Setup Instructions

Follow these step-by-step instructions to set up and run the project locally.

# Prerequisites -
Ensure you have the following installed on your machine:
* *Node.js* : `v18.17.0` or higher
* *Package Manager* : `npm` or `yarn`

---

## Clone & Install Dependencies

```bash
# Clone the repository
git clone [https://github.com/JaiSequare/ticktock-timesheet-app.git](https://github.com/JaiSequare/ticktock-timesheet-app.git)

# Navigate into the project directory
cd timesheet-app

# Install npm dependencies
npm install


# Getting Started
First, run the development server:

```bash
npm run dev
# or
yarn dev
```

---

# Start the dev server

npm run dev

*Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.*

## Deploy on Vercel

Follow these steps to deploy the project on Vercel:

* *Push your project to a GitHub repository.*
* *Sign in to Vercel using your GitHub account.*
* *Click **Add New -> Project**.*
* *Import the GitHub repository.*
* *Configure the project settings (if required).*
* *Add all required environment variables in **Project Settings -> Environment Variables** if present.*
* *Click **Deploy**.*
* *Wait & Open the generated Vercel URL to access your application.*
